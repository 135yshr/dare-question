# この回答、だれの？

開発者イベント向けの自己紹介当てっこアプリです。参加者はスマホで選択式の質問に答え、司会画面に1問ずつ出る回答が「だれのものか」をスマホで投票します。

- 参加者はログイン不要（裏側で Firebase の匿名認証を使います）
- 司会は Google ログイン（`admins` に登録したアカウントのみ）
- ビルド不要。`public/` をそのまま Firebase Hosting に置くだけ

## 画面

| URL | 用途 |
| --- | --- |
| `/` | 参加者用（スマホ） |
| `/host` | 司会用（プロジェクター）。参加用 QR コードも表示 |

## セットアップ（初回のみ）

1. [Firebase コンソール](https://console.firebase.google.com/)でプロジェクトを作成（無料の Spark プランで動きます）
2. **Firestore Database** を作成（本番モード、リージョンは `asia-northeast1` など）
3. **Authentication** →「ログイン方法」で **匿名** と **Google** を有効化
4. 「プロジェクトの設定」→「マイアプリ」でウェブアプリを追加し、表示された設定を `public/firebase-config.js` に貼り付け
5. `.firebaserc` の `REPLACE_ME` をプロジェクト ID に置き換え
6. デプロイ

   ```sh
   npm i -g firebase-tools
   firebase login
   firebase deploy
   ```

7. Firestore コンソールで **司会を登録**：コレクション `admins` に、ドキュメント ID を司会の Google メールアドレス（例：`you@example.com`）にしたドキュメントを作成（フィールドは何でも可。例：`role: "host"`）

## 当日の流れ

1. 司会が `/host` を開いて Google でログイン
2. 一人あたりの質問数を ＋／− で設定
3. 参加者が QR コードから `/` を開き、ニックネームを入れて質問に回答
4. 2人以上集まったら「当てっこを始める」
5. 投票が集まったら「締め切って正解を発表」→「次の問題へ」を繰り返す
6. 次の回に使うときは「全部リセット」

## 仕様メモ

- 質問は `public/questions.js` の質問プールから一人ごとにランダムに選ばれます。参加者は「別の質問にする」で引き直せます
- 出題は毎回別の人の回答を1つずつ。同じ人が連続しないように選びます
- 投票の選択肢は、登録者が 8 人以下なら全員、9 人以上なら正解＋ランダム 3 人の 4 択（`app.js` の `ALL_CHOICES_MAX`）
- 出題された本人の画面には「これはあなたの回答です」と出て、投票できません

## セキュリティルールで守っていること

開発者向けイベントなので、開発者ツールで覗かれても答えがばれないようにしています。

- 公開されるのはニックネームと、出題中の「質問と回答」だけ
- 各自の回答一覧（`answers`）、正解（`game/secret`）、投票（`votes`）、「あなたの番」通知（`turns`）は本人と司会しか読めません
- 投票は受付中の問題・選択肢にある名前に対してだけ、出題された本人以外が書き込めます
- 進行（`game`）を変えられるのは司会だけ

## 無料枠の目安

参加者は自分の投票と通知だけを購読するので、50 人・30 問程度なら Spark プランの読み取り上限（1 日 5 万回）に十分収まります。
